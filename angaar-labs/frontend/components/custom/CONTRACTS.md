# Component contracts (from the design synthesis)

Read DESIGN.md first for tokens, typography, motion and the cursor policy.

## components/custom/tone.ts
**Exports:** type Tone; TONE_LIST; toneStyle(tone): CSSProperties; TONE_CLASS = { text, tint, dot, rule, ring }; toneFromChange(n, lowerIsBetter?)

No React, no imports. `Tone = 'neutral' | 'success' | 'warning' | 'info' | 'danger' | 'terracotta' | 'plum' | 'primary'`. `toneStyle(tone)` returns `{ '--tone': 'var(--success)' }` (neutral → `var(--muted-foreground)`, danger → `var(--destructive)`). `TONE_CLASS.text = 'text-(--tone)'`, `.tint = 'bg-[color-mix(in_oklch,var(--tone)_14%,transparent)] text-(--tone)'`, `.dot = 'bg-(--tone)'`, `.rule = 'shadow-[inset_3px_0_0_var(--tone)]'`, `.ring = 'ring-(--tone)'`. Every tone-aware component sets the style once and uses these constant strings, so Tailwind sees every class statically. `toneFromChange` returns success/danger/neutral (0 → neutral, fixing parts.tsx:29's green 0%).

## components/custom/status-registry.ts
**Exports:** type KnownStatus; type StatusKind; STATUS: Record<string, { tone: Tone; label: string; inFlight?: boolean }>; STATUS_BY_KIND: Partial<Record<StatusKind, Record<string, Partial<entry>>>>; statusEntry(status, kind?)

Imports only tone.ts. Kinds: order, shipment, return, payment, refund, doctor, wholesale, appointment, prescription, payout, enquiry, coupon, review, stream, banner, staff, inventory, message, import, channel. Base table: success = DELIVERED, PAID, APPROVED, ACTIVE, SUCCESS, COMPLETED, PUBLISHED, SENT, LIVE, OPEN, ISSUED, VERIFIED, PASSED, IN_STOCK; warning = PENDING, PENDING_PAYMENT, UNDER_REVIEW (inFlight), PROCESSING (inFlight), PACKED, RETURN_REQUESTED, PARTIALLY_PAID, REQUESTED, PICKED_UP, RECEIVED, NEW, QUEUED, RUNNING (inFlight), USED_UP, ENDED, LOW_STOCK, UNPAID, PAUSED, STARTED, NOT_PASSED; info = CONFIRMED, SHIPPED (inFlight), OUT_FOR_DELIVERY (inFlight), PICKUP_SCHEDULED, PICKUP_BOOKED, IN_TRANSIT (inFlight), IN_PROGRESS (inFlight), SCHEDULED, BOOKED; danger = CANCELLED, UNDELIVERED, REJECTED, FAILED, SUSPENDED, NO_SHOW, RTO, LOST, OUT_OF_STOCK, BLOCKED; neutral = RETURNED, REFUNDED, DRAFT, ARCHIVED, CLOSED, CREATED, SKIPPED, HIDDEN, EXPIRED, OFF, D2C, RESTOCKED; plum = B2B, WHOLESALE. Per-kind overrides: refund PENDING → warning inFlight; payout PENDING → warning; stream COMING_SOON → tone neutral, label 'Not open yet' (admin only; doctor-facing lists filter it); enquiry CLOSED → neutral; coupon OFF → label 'Switched off'. Labels come from the existing maps (APPOINTMENT_LABEL in lib/care.ts, STATUS_LABEL maps in payouts/refunds/payments) folded in; unknown → `{ tone: 'neutral', label: humanize(status) }` plus a one-time `console.warn` in development. `KnownStatus` is the union of the table's keys so TypeScript flags typos at call sites.

## components/custom/typography.tsx
**Exports:** Eyebrow, Display, Title, Folio, Mono, SectionLabel

Imports ui nothing; `cn` from '@/lib/utils'. `Eyebrow({ as?: 'p'|'span'|'div'|'th', className, children })` → `text-[0.6875rem]/none font-semibold uppercase tracking-[0.12em] text-muted-foreground`. `Display({ level: 1|2, as?: 'h1'|'h2'|'p'|'span', className, children })` → level 1: `font-display text-4xl/[1.1] font-medium tracking-[-0.015em] [font-variation-settings:'opsz'_72] text-balance`; level 2: `font-display text-[1.75rem]/[1.15] font-medium [font-variation-settings:'opsz'_48] ledger`. `Title({ as?: 'h2'|'h3'|'div', className, children })` → `font-display text-lg/[1.3] font-medium`. `Folio({ prefix?: string = 'No.', value: string, className })` → eyebrow prefix + `font-display italic text-lg ledger` value, used on prescriptions, order sheets, invoices. `Mono({ upper?: boolean, className, children })` → `font-mono text-[0.8125rem]` (+ `uppercase font-medium` when upper) for order numbers, SKUs, references. `SectionLabel({ children, action?: ReactNode })` → an Eyebrow row with an optional right-aligned action (replaces the uppercase h3 headings inside sheets). ## components/custom/number.tsx
**Exports:** Money, Num, Pct, Delta, CountUp, NUMBER_TIMING

'use client'. Imports `NumberFlow` from '@number-flow/react', tone.ts, `formatMoney/formatNumber/formatCompact` from '@/lib/format'. Shared `NUMBER_TIMING = { transformTiming: { duration: 600, easing: 'cubic-bezier(.22,1,.36,1)' }, spinTiming: { duration: 500 }, opacityTiming: { duration: 250 } }`; `respectMotionPreference` stays on. All accept `className` and `animate?: boolean` (default true; `false` renders the plain Intl string in a `<span className="ledger">`, used in table cells). `Money({ value, compact?, animate?, strike?, tone? })` → `NumberFlow locales="en-IN" format={{ style: 'currency', currency: 'INR', maximumFractionDigits: 0 }}` (compact: `notation: 'compact'`), ₹ followed by a thin space, `strike` renders `line-through text-muted-foreground`. `Num({ value, format?: Intl.NumberFormatOptions, animate? })`. `Pct({ value, signed?, animate? })` → `{ style: 'percent', maximumFractionDigits: 1, signDisplay }`. `Delta({ value: number | null, unit?: '%' | 'pt', lowerIsBetter? })` → the tone chip used by StatCard: `inline-flex h-5 items-center gap-0.5 rounded-full px-1.5 text-xs font-medium` + `TONE_CLASS.tint`, ArrowUpRight/ArrowDownRight icon, `—` chip in neutral for 0, 'No earlier data' text in muted for null. `CountUp({ value, from?, duration? })` for live countdowns. Inside a display-size parent the digits inherit Fraunces; in cells they stay Public Sans; everything carries `ledger`. Wrappers set `display: inline-flex; overflow: visible` so digits never clip mid-animation.

**Exports:** MotionRoot, Reveal, Stagger, useMotionSafe, EASE, m (re-export)
